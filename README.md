# Princess Poppy's Math Quest

A colourful static math exercise for 5-7 year olds. It uses a princess story, visual counting jewels, and only addition and subtraction.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

## Deploy on Vercel

Use `outputs/princess-math` as the project root. No build command is required, and the output directory can be left blank because the app is plain HTML, CSS, and JavaScript.
